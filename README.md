# Воздух Бишкека

Сайт о качестве воздуха в Бишкеке: видно ли сегодня горы, сколько это сигарет в день, карта районов и история по часам.

## Как это работает

| Часть | Где | Что делает |
|---|---|---|
| Данные | `scripts/update.py` | Раз в час забирает станции [meteo.kg](https://www.meteo.kg/air-quality-data.json). Если их свежайшее измерение старше двух часов, берёт датчики открытой сети [Sensor.Community](https://sensor.community) в радиусе 14 км от центра. Сети не смешиваются: срез помечен источником |
| Хранение | `data/latest.json`, `data/history.json` | Последний срез и история по часам за 14 дней |
| Расписание | `.github/workflows/update.yml` | GitHub Actions в 20 минут каждого часа запускает обновление, коммитит данные и публикует сайт в GitHub Pages |
| Страница | `index.html` | Собирается из `src/app.html` и `src/scene.svg` командой `python scripts/build.py`. Читает файлы из `data/` и перечитывает их каждые 10 минут |

## Правка страницы

1. Меняйте `src/app.html`.
2. Запустите `python scripts/build.py`.
3. Закоммитьте `src/app.html` и `index.html`.

## Обновить данные вручную

Actions → «Обновление данных и публикация» → Run workflow.

## Свой домен

1. Settings → Pages → Custom domain: укажите домен.
2. У регистратора домена:
   - для поддомена (`air.example.kg`) добавьте CNAME‑запись на `nurgazievrakhat.github.io`;
   - для корневого домена (`example.kg`) добавьте A‑записи `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
3. Когда GitHub выпустит сертификат, включите Enforce HTTPS.

## Методика

- Главная метрика PM2.5. Категории по шкале EPA 2024, норма ВОЗ 15 мкг/м³ за сутки.
- Сигареты: пересчёт Berkeley Earth, 22 мкг/м³ за сутки ≈ 1 сигарета. Это ориентир масштаба, а не медицинская оценка.
- Станции, которые расходятся с соседями в радиусе 4 км больше чем на 45% и 60 мкг/м³, помечаются и не попадают в рейтинг и раскраску карты.
- Дымка на горах иллюстративная: затухание по закону Бугера — Ламберта с подобранной константой.
